# Feedback-Linked EDA Summary

## 목적

이 문서는 받은 코멘트가 실제 분석과 코드에 어떻게 반영되었는지, 그리고 EDA가 그 판단을 뒷받침하는지 정리한다.

핵심 방향은 인과추론 중심 설명을 낮추고, 성장 유망 매장 **분류**, 리뷰 텍스트 신호, 외부 상권 변수, ROI 연결을 전면에 두는 것이다.

## 코멘트 반영 현황

- 알고리즘 비교와 모델 선택 근거가 체계적임: 기본 모델, 성장 알파 모델, 알파+텍스트 분류 모델을 같은 시간 기준 분할로 비교 (반영 완료)
- 댓글 주체 분리는 좋고, 텍스트 자체에서 더 깊은 정보를 끌어내면 좋겠음: 리뷰 원문 감성/주제 피처를 성장 유망 매장 분류 모델에 통합 (반영 완료)
- 매장 내부 신호 중심이고 외부 환경 변수가 약함: 서울 211개 매장에 대해 외부 상권 객단가/매출/주문수 결합 모델과 내부 모델 비교 (반영 완료, 확장 필요)
- DID/PSM/Event Study는 기대 의도와 다르고 분류에 집중하면 좋겠음: 인과추론은 평균 효과 검증 보조 근거로 낮추고, 최종 의사결정은 성장 라벨 분류와 상위 추천 성능 중심으로 재정렬 (반영 완료)
- 예측과 투자효과가 분리되어 있으며 투자효과 시뮬레이션이 필요함: 성장 확률 기반 기대 추가 주문, 기대 마진, 기대 투자효과 시뮬레이션 추가 (반영 완료)

## 깊이 있는 EDA 근거

- 성장 그룹 평균 주문수는 169.1733, 비성장 그룹은 68.1782으로 148.13% 높고, 효과크기 효과크기는 0.4162이다.
- 성장 그룹 평균 리뷰수는 14.8969, 비성장 그룹은 8.8084으로 69.12% 높다.
- 답글률도 성장 그룹 0.5505, 비성장 그룹 0.4702으로 높아 운영 신호가 분류에 들어갈 근거가 있다.
- 결과 설명용 Growth Alpha는 성장 그룹 2.9508, 비성장 그룹 -1.2651으로 명확히 갈린다.
- 리뷰 텍스트 감성은 성장 그룹 0.6831, 비성장 그룹 0.6709으로 성장 그룹이 높다.
- 부정 리뷰율은 성장 그룹 0.031, 비성장 그룹 0.04으로 22.67% 낮다.
- 재주문 언급률은 성장 그룹 0.072, 비성장 그룹 0.0644으로 11.83% 높다.
- 성장 알파 모델 성능은 0.6078, 텍스트 결합 모델 성능은 0.6148로 개선되었다.
- NLP 결합 모델의 baseline 대비 성능 개선폭는 0.0088이다.
- NLP 결합 모델의 최상위 예측 decile 실제 성장률은 40.40%, 최하위 decile은 10.80%로 ranking lift가 확인된다.
- 서울 외부 상권 변수는 성장 그룹이 모든 항목에서 일방적으로 높지 않다. 따라서 단독 지표가 아니라 내부 신호를 보완하는 상권 맥락 변수로 해석한다.
- 기본 투자효과 시나리오에서 A등급 평균 기대 투자효과는 150,409원, D등급은 -22,198원으로 등급이 투자 우선순위와 연결된다.

## 발표용 정리 문장

```text
피드백을 반영해 인과추론은 평균 효과 검증 근거로 두고, 최종 의사결정은 성장 유망 매장 분류 모델로 재정렬했습니다.
리뷰 원문 NLP 피처를 모델에 직접 넣었고, 외부 상권 변수는 단독 판단이 아닌 상권 맥락 보정으로 사용했습니다.
마지막으로 분류 확률을 투자효과 시뮬레이션으로 연결해 '예측은 좋은데 그래서 얼마의 투자효과가 있는가'라는 질문까지 답하도록 보완했습니다.
```

## 남은 한계

- NLP는 아직 사전 기반이므로 문장 임베딩이나 한국어 분류 모델로 고도화할 수 있다.
- 외부 상권 데이터는 현재 서울 211개 매장 중심이며, 행정동/좌표 단위 결합과 유동인구·경쟁 밀도·임대료 확장이 필요하다.
- 투자효과는 실제 마진율과 집행 비용이 확정되면 시나리오가 아니라 실측 기반으로 재계산해야 한다.
