# Score Sensitivity Visualization Guide

## 1. 분석 목적

GroMong Score는 5개 지수로 구성된다.

- 성장 확률
- Growth Alpha
- 리뷰 성장
- 운영 역량
- 안정성

이번 분석의 목적은 **현재 가중치가 임의로 보이지 않도록 검증 근거를 만드는 것**이다. 즉, 가중치를 다르게 설정해도 상위 추천 매장이 얼마나 유지되는지 확인한다.

발표 핵심 메시지:

```text
현재 점수는 하나의 임의 가중치에만 의존하지 않습니다. 가중치를 여러 방식으로 바꿔도 Top 100 매장의 상당수가 유지되어, 추천 결과가 비교적 안정적임을 확인했습니다.
```

## 2. 비교한 가중치 시나리오

| 시나리오 | 목적 |
| --- | --- |
| 현재 공식 가중치 | 기존 GroMong Score 기준 |
| 성장확률 강화 | 모델 예측 확률을 더 강하게 반영 |
| Growth Alpha 강화 | 브랜드/카테고리 보정 후 초과 성장성을 더 강하게 반영 |
| 리뷰 성장 강화 | 고객 반응 증가를 더 강하게 반영 |
| 운영 역량 강화 | 답글률, 답글 속도 등 운영 지표를 더 강하게 반영 |
| 안정성 강화 | 변동성이 작고 안정적인 매장을 더 강하게 반영 |
| 서울 상권 적합도 강화 | 서울 매장의 외부 상권 적합도를 더 강하게 반영 |

## 3. 핵심 결과

| 시나리오 | Top100 겹침률 | 순위 상관 | A등급 수 |
| --- | ---: | ---: | ---: |
| 현재 공식 가중치 | 100% | 1.000 | 84 |
| 성장확률 강화 | 91% | 0.990 | 116 |
| Growth Alpha 강화 | 89% | 0.964 | 75 |
| 리뷰 성장 강화 | 78% | 0.976 | 56 |
| 운영 역량 강화 | 94% | 0.983 | 115 |
| 안정성 강화 | 82% | 0.959 | 83 |
| 서울 상권 적합도 강화 | 95% | 0.995 | 81 |

해석:

- 모든 대체 시나리오에서 현재 Top 100의 78~95%가 유지됐다.
- 순위 상관도 0.959~0.995로 높게 나타났다.
- 따라서 현재 스코어링 결과는 특정 가중치 하나에만 과도하게 의존한다고 보기 어렵다.
- 다만 리뷰 성장 강화와 안정성 강화에서는 Top 100 겹침률이 상대적으로 낮아, 해당 지표가 추천 순위에 영향을 크게 줄 수 있음을 확인했다.

## 4. 시각화별 설명

### 4.1 `top100_overlap_by_scenario.svg`

파일:

- `analysis_outputs/sensitivity/charts/top100_overlap_by_scenario.svg`

목적:

- 현재 공식 점수의 Top 100 매장이 가중치 변경 후에도 얼마나 유지되는지 보여준다.

핵심 수치:

- 성장확률 강화: 91%
- Growth Alpha 강화: 89%
- 리뷰 성장 강화: 78%
- 운영 역량 강화: 94%
- 안정성 강화: 82%
- 서울 상권 적합도 강화: 95%

발표 문장:

```text
가중치를 여러 방식으로 바꿔도 현재 Top 100 매장의 최소 78%, 최대 95%가 유지됐습니다. 따라서 추천 결과가 특정 가중치 하나에만 좌우되지는 않는다고 볼 수 있습니다.
```

주의점:

- Top 100 겹침률이 높다는 것은 결과 안정성을 의미하지만, 이것만으로 실제 투자 성공을 보장하지는 않는다.

### 4.2 `rank_correlation_by_scenario.svg`

파일:

- `analysis_outputs/sensitivity/charts/rank_correlation_by_scenario.svg`

목적:

- 현재 순위와 대체 시나리오 순위가 전체적으로 얼마나 비슷한지 확인한다.

핵심 수치:

- 모든 대체 시나리오의 순위 상관이 0.959 이상이다.

해석:

- 상위 100개뿐 아니라 전체 매장 순위 구조도 현재 점수와 크게 다르지 않다.
- 현재 점수 체계의 안정성을 보여주는 보조 근거다.

### 4.3 `mean_score_by_scenario.svg`

파일:

- `analysis_outputs/sensitivity/charts/mean_score_by_scenario.svg`

목적:

- 가중치 시나리오별 전체 평균 점수 변화를 보여준다.

해석:

- 안정성 강화 시나리오는 평균 점수가 높아지고, Growth Alpha 강화 시나리오는 평균 점수가 낮아진다.
- 이는 지표별 점수 분포가 다르기 때문에 발생한다.
- 발표에서는 절대 평균보다 Top 매장 유지율과 순위 상관을 더 중요한 지표로 설명한다.

### 4.4 `grade_counts_by_scenario.svg`

파일:

- `analysis_outputs/sensitivity/charts/grade_counts_by_scenario.svg`

목적:

- 가중치가 바뀔 때 A/B/C/D 등급 분포가 어떻게 달라지는지 보여준다.

핵심 수치:

- 현재 A등급: 84개
- 성장확률 강화 A등급: 116개
- 리뷰 성장 강화 A등급: 56개
- 운영 역량 강화 A등급: 115개

해석:

- 어떤 지표를 강조하느냐에 따라 A등급 매장 수는 달라진다.
- 따라서 최종 발표에서는 “A등급은 절대 투자 확정이 아니라 우선 검토 후보군”이라고 설명해야 한다.

### 4.5 `top100_stability_top20.svg`

파일:

- `analysis_outputs/sensitivity/charts/top100_stability_top20.svg`

목적:

- 현재 상위 20개 매장이 7개 시나리오 중 몇 번이나 Top 100에 유지되는지 보여준다.

핵심 결과:

- 현재 상위 20개 매장은 7개 시나리오 모두에서 Top 100을 유지했다.

해석:

- 최상위권 매장은 가중치 변화에도 안정적으로 우수 후보로 남는다.
- 다만 최상위권이 본그룹 백반·죽·국수 카테고리에 많이 몰려 있어, 다음 단계에서 브랜드/카테고리 보정 순위를 추가해야 한다.

발표 문장:

```text
상위권 후보는 가중치를 바꿔도 대부분 유지됐지만, 특정 브랜드와 카테고리에 집중되는 한계도 확인했습니다. 그래서 최종 단계에서는 브랜드/카테고리 내부 순위까지 함께 제시하는 방식으로 보완하겠습니다.
```

## 5. 프로젝트 차별점으로 연결

이번 분석은 다음 차별점을 강화한다.

1. 점수 기준을 만들고 끝내지 않고, 가중치를 바꿔 안정성을 검증했다.
2. Growth Alpha, 고객 리뷰, 운영 역량, 안정성 중 어떤 요소가 순위를 흔드는지 확인했다.
3. 스코어가 절대 판단이 아니라 우선 검토 후보군을 선별하는 도구임을 명확히 했다.
4. 제공 데이터가 특정 브랜드에 치우친 한계를 숨기지 않고, 브랜드/카테고리 보정 필요성을 분석 결과로 드러냈다.

## 6. 다음 작업

다음 단계는 **브랜드/카테고리 보정 점수**다.

필요한 이유:

- 현재 최상위권 매장이 본그룹 백반·죽·국수에 많이 집중된다.
- 교수님이 “본그룹과 굽네치킨밖에 없는데 일반화할 수 있느냐”고 물을 수 있다.
- 전체 순위와 별도로 카테고리 내부 순위를 제시하면, 제한된 데이터 안에서도 더 공정하고 설명 가능한 결과물이 된다.
