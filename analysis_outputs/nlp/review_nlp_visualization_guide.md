# Review NLP Visualization Guide

## 1. 분석 목적

이번 단계의 목적은 기존 주문, 리뷰 수, 평점 중심 분석에서 한 단계 더 들어가서 **고객이 실제로 남긴 리뷰 원문**을 분석하는 것이다.

교수님에게 강조할 핵심은 기술 이름이 아니라 다음 메시지다.

```text
이 프로젝트는 단순히 주문 수가 많은 매장을 찾는 것이 아니라, 고객 리뷰 원문에 담긴 긍정/부정 신호와 재주문 의도까지 함께 반영해 성장 유망 매장을 판단한다.
```

## 2. 사용 데이터

- 원천 데이터: `data/reviews_주요_성과_변수.json`
- 분석 단위: 매장-월 단위
- 결합 기준: `platform_shop_id`, `year_month`
- 비교 기준: `growth_label_top30`
  - 1: 성장 상위 30% 매장-월
  - 0: 그 외 매장-월

## 3. 분석 방식

리뷰 원문에 대해 파일럿 NLP 분석을 수행했다.

- 긍정 키워드 카운트
- 부정 키워드 카운트
- 맛, 양, 배달, 가격, 서비스, 재주문 주제 분류
- 텍스트 감성 점수 산출
- 별점과 텍스트 감성이 어긋나는 사례 탐색

현재 단계는 외부 대형 언어모델 API를 호출한 분석이 아니라, 제공 리뷰 원문에 대해 직접 설계한 한국어 키워드 사전 기반 파일럿 분석이다. 따라서 발표에서는 **"리뷰 원문 기반 NLP 파일럿"** 또는 **"고객 언어 신호 분석"**이라고 표현하는 것이 안전하다.

## 4. 핵심 결과

| 구분 | 성장 외 매장 | 성장 상위 매장 |
| --- | ---: | ---: |
| 분석 리뷰 수 | 3,782 | 2,696 |
| 포함 매장 수 | 967 | 889 |
| 평균 텍스트 감성 | 0.6709 | 0.6831 |
| 긍정 리뷰 비율 | 85.62% | 87.10% |
| 부정 리뷰 비율 | 4.00% | 3.10% |
| 재주문 언급률 | 6.44% | 7.20% |
| 배달 언급률 | 14.99% | 15.64% |

해석:

- 성장 상위 매장은 성장 외 매장보다 평균 텍스트 감성이 높다.
- 성장 상위 매장은 긍정 리뷰 비율이 높고 부정 리뷰 비율이 낮다.
- 성장 상위 매장은 "또 주문", "재주문"과 같은 재구매 의도 신호가 더 자주 등장한다.
- 차이가 매우 큰 수준은 아니지만, 주문/리뷰 수만으로는 볼 수 없던 고객 언어 기반의 성장 신호를 추가로 확인했다는 점에서 차별점이 있다.

## 5. 시각화별 설명

### 5.1 `sentiment_by_growth_label.svg`

파일:

- `analysis_outputs/nlp/charts/sentiment_by_growth_label.svg`

목적:

- 성장 상위 매장과 성장 외 매장의 텍스트 감성, 긍정 리뷰 비율, 부정 리뷰 비율을 비교한다.

핵심 수치:

- 평균 텍스트 감성: 성장 외 0.6709, 성장 상위 0.6831
- 긍정 리뷰 비율: 성장 외 85.62%, 성장 상위 87.10%
- 부정 리뷰 비율: 성장 외 4.00%, 성장 상위 3.10%

발표 문장:

```text
성장 상위 매장은 리뷰 원문에서도 긍정 표현이 더 많고 부정 표현이 더 적었습니다. 즉 주문량뿐 아니라 고객이 남긴 언어에서도 성장 매장의 신호가 일부 확인됩니다.
```

주의점:

- 키워드 사전 기반 분석이므로 문맥을 완벽하게 이해하는 감성 모델은 아니다.
- 중간발표에서는 "강한 결론"보다 "추가 신호를 확인했다"는 표현이 적절하다.

### 5.2 `review_topic_rates_by_growth_label.svg`

파일:

- `analysis_outputs/nlp/charts/review_topic_rates_by_growth_label.svg`

목적:

- 리뷰에서 어떤 주제가 많이 언급되는지 성장 상위 매장과 성장 외 매장을 비교한다.

핵심 수치:

- 맛 언급률: 성장 외 71.38%, 성장 상위 71.51%
- 양 언급률: 성장 외 12.75%, 성장 상위 12.68%
- 배달 언급률: 성장 외 14.99%, 성장 상위 15.64%
- 재주문 언급률: 성장 외 6.44%, 성장 상위 7.20%

해석:

- 맛 언급은 두 그룹 모두 높아 F&B 리뷰의 기본 주제임을 보여준다.
- 성장 상위 매장은 재주문 언급률이 더 높아, 단순 만족보다 반복 구매 가능성 측면에서 의미가 있다.

발표 문장:

```text
성장 상위 매장은 맛에 대한 반응뿐 아니라 재주문 의도 표현이 더 높게 나타났습니다. 그래서 리뷰 원문은 향후 성장 유망 매장을 판단하는 보조 신호로 사용할 수 있습니다.
```

### 5.6 `rating_sentiment_mismatch_counts.svg`

파일:

- `analysis_outputs/nlp/charts/rating_sentiment_mismatch_counts.svg`

목적:

- 별점과 리뷰 원문 감성이 어긋나는 사례가 있는지 확인한다.

해석:

- 별점은 높지만 텍스트에 부정 표현이 섞인 리뷰, 별점은 낮지만 긍정 표현이 있는 리뷰를 따로 볼 수 있다.
- 이는 평점 평균만 보는 방식의 한계를 보완한다.

발표 문장:

```text
별점은 숫자 하나로 요약되지만, 리뷰 원문에는 불만이나 재주문 의도 같은 세부 신호가 남아 있습니다. 그래서 본 프로젝트는 평점뿐 아니라 텍스트 자체를 함께 분석했습니다.
```

## 6. 프로젝트 차별점으로 연결하는 방법

이번 NLP 보강은 프로젝트의 차별점을 다음처럼 강화한다.

1. 단순 매출/주문 순위가 아니라 고객 언어 신호까지 본다.
2. 리뷰 수와 평점뿐 아니라 긍정/부정 키워드와 재주문 의도를 분리한다.
3. Growth Alpha, 외부 상권 데이터, 리뷰 원문 NLP를 결합해 성장 유망 매장을 다면적으로 판단한다.
4. 데이터가 본그룹/굽네치킨 중심이라는 한계를 숨기지 않고, 브랜드/카테고리 보정과 고객 반응 분석으로 방어한다.

## 7. 한계

- 키워드 사전 기반 분석이므로 문맥, 반어, 복합 감정을 완벽히 처리하지 못한다.
- 리뷰 원문이 있는 매장과 없는 매장 사이에 표본 편향이 있을 수 있다.
- 현재 분석은 성장 상위 여부와 리뷰 언어의 관계를 확인하는 단계이며, 인과관계로 말하면 안 된다.

## 8. 다음 작업
