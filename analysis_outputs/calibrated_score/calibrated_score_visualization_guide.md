# Calibrated Score Visualization Guide

## 1. 분석 목적

이번 단계의 목적은 제공 데이터가 **본그룹과 굽네치킨 중심**이라는 한계를 정면으로 인정하고, 전체 점수만으로 매장을 줄 세우는 방식의 편중 문제를 보완하는 것이다.

핵심 메시지:

```text
전체 점수만 보면 특정 브랜드와 카테고리에 상위 후보가 몰릴 수 있습니다. 그래서 전체 순위와 별도로 브랜드 내부, 카테고리 내부에서 상대적으로 우수한 매장을 함께 평가했습니다.
```

## 2. 보정 점수 설계

보정 점수는 기존 GroMong Score를 유지하면서, 브랜드 내부 상대점수와 카테고리 내부 상대점수를 추가했다.

```text
calibrated_score =
0.50 * GroMong Score
+ 0.25 * 브랜드 내부 percentile
+ 0.25 * 카테고리 내부 percentile
```

이 공식의 의미:

- GroMong Score 50%: 기존 모델/EDA/상권/운영 신호를 유지한다.
- 브랜드 내부 percentile 25%: 같은 브랜드 안에서 상대적으로 잘하는 매장을 드러낸다.
- 카테고리 내부 percentile 25%: 같은 업종 안에서 상대적으로 잘하는 매장을 드러낸다.

주의:

- 보정 점수는 기존 점수를 대체하는 최종 정답이 아니다.
- 전체 순위와 함께 제시하는 **공정성 보완 지표**다.

## 3. 핵심 결과

| 항목 | 결과 |
| --- | ---: |
| 기존 Top100과 보정 Top100 겹침 | 92개 |
| 보정 후 신규 Top100 진입 | 8개 |
| 기존 Top100 내 굽네치킨 | 8개 |
| 보정 Top100 내 굽네치킨 | 16개 |
| 기존 Top100 내 치킨 | 7개 |
| 보정 Top100 내 치킨 | 11개 |
| 기존 Top100 내 피자 | 1개 |
| 보정 Top100 내 피자 | 5개 |
| 기존 Top100 내 백반·죽·국수 | 92개 |
| 보정 Top100 내 백반·죽·국수 | 84개 |

해석:

- 기존 상위권 후보 92개는 보정 후에도 유지되어, 기존 점수의 핵심 구조는 크게 흔들리지 않았다.
- 동시에 8개 매장이 새로 진입해 치킨/피자/굽네치킨 쪽 후보가 더 드러났다.
- 이는 “기존 결과를 무너뜨리는 보정”이 아니라 “편중을 완화하는 보정”으로 해석할 수 있다.

## 4. 시각화별 설명

### 4.1 `overall_vs_calibrated_score.svg`

파일:

- `analysis_outputs/calibrated_score/charts/overall_vs_calibrated_score.svg`

목적:

- 기존 GroMong Score와 보정 점수의 관계를 확인한다.
- 어떤 카테고리 매장이 보정 후 위로 올라가거나 내려가는지 시각적으로 보여준다.

해석:

- 대각선 근처에 있는 매장은 기존 점수와 보정 점수가 비슷하다.
- 대각선보다 위에 있는 매장은 브랜드/카테고리 내부에서 상대적으로 우수해 보정 점수가 높아진 매장이다.
- 대각선보다 아래에 있는 매장은 전체 점수는 높지만 같은 브랜드/카테고리 내부 상대점수에서는 덜 돋보이는 매장이다.

발표 문장:

```text
보정 점수는 기존 점수를 완전히 뒤집는 것이 아니라, 같은 브랜드와 같은 카테고리 안에서 상대적으로 우수한 매장을 더 잘 보이게 하는 역할을 합니다.
```

### 4.2 `category_top100_counts_before_after.svg`

파일:

- `analysis_outputs/calibrated_score/charts/category_top100_counts_before_after.svg`

목적:

- 보정 전후 Top100에 포함된 카테고리별 매장 수를 비교한다.

핵심 수치:

- 백반·죽·국수: 92개에서 84개
- 치킨: 7개에서 11개
- 피자: 1개에서 5개

해석:

- 기존 Top100은 백반·죽·국수에 강하게 집중되어 있었다.
- 보정 후 치킨과 피자 카테고리의 우수 후보가 더 많이 드러났다.

발표 문장:

```text
보정 전에는 Top100이 백반·죽·국수에 과도하게 몰려 있었지만, 보정 후에는 치킨과 피자 카테고리의 상대적 우수 매장도 함께 드러났습니다.
```

### 4.3 `category_avg_score_before_after.svg`

파일:

- `analysis_outputs/calibrated_score/charts/category_avg_score_before_after.svg`

목적:

- 카테고리별 평균 점수가 보정 후 어떻게 달라지는지 확인한다.

핵심 수치:

- 백반·죽·국수 평균: 55.29에서 52.65
- 치킨 평균: 51.13에서 51.36
- 피자 평균: 46.07에서 46.19

해석:

- 보정 후 백반·죽·국수의 평균 점수는 낮아졌다.
- 치킨과 피자는 평균 점수가 소폭 올라갔다.
- 이는 카테고리 내부 상대점수를 반영하면서 편중이 일부 완화된 결과다.

주의:

- 평균 점수가 올라갔다고 해당 카테고리 전체가 더 좋다는 뜻은 아니다.
- 같은 카테고리 안에서 우수한 후보를 드러내기 위한 보정 결과로 해석해야 한다.

### 4.4 `brand_A_counts_before_after.svg`

파일:

- `analysis_outputs/calibrated_score/charts/brand_A_counts_before_after.svg`

목적:

- 브랜드별 A등급 매장 수가 보정 전후 어떻게 바뀌는지 확인한다.

핵심 수치:

- 본그룹 A등급: 78개에서 130개
- 굽네치킨 A등급: 6개에서 31개

해석:

- 보정 점수는 그룹 내부 percentile을 포함하므로 A등급 수가 기존보다 늘어날 수 있다.
- 이 차트는 최종 투자 확정 매장 수가 아니라, 브랜드 내부에서 상대적으로 우수한 후보군이 얼마나 드러나는지 보여주는 보조 자료다.

주의:

- 보정 A등급은 기존 A등급과 같은 의미의 절대 등급이 아니다.
- 발표에서는 “보정 후보군”이라고 표현해야 한다.

### 4.5 `top100_overlap_after_calibration.svg`

파일:

- `analysis_outputs/calibrated_score/charts/top100_overlap_after_calibration.svg`

목적:

- 기존 Top100과 보정 Top100이 얼마나 겹치는지 보여준다.

핵심 수치:

- 겹침: 92개
- 신규 진입: 8개

해석:

- 기존 결과가 크게 흔들리지는 않았다.
- 다만 8개 매장이 새로 진입해, 기존 전체 순위에서는 덜 보였던 브랜드/카테고리 내부 우수 후보가 추가로 발굴됐다.

발표 문장:

```text
보정 후에도 기존 Top100 중 92개가 유지되어 기존 스코어의 안정성은 유지됐습니다. 동시에 8개 후보가 새로 진입해 브랜드와 카테고리 편중을 일부 완화했습니다.
```

### 4.6 `category_top10_calibrated_scores.svg`

파일:

- `analysis_outputs/calibrated_score/charts/category_top10_calibrated_scores.svg`

목적:

- 카테고리별 보정 점수 Top 후보를 보여준다.
- 전체 Top 순위만 볼 때 가려지는 치킨/피자 카테고리의 우수 후보를 제시한다.

해석:

- 백반·죽·국수 상위권은 기존 전체 순위에서도 강하게 나타난다.
- 치킨과 피자 카테고리는 전체 순위에서는 상대적으로 덜 보였지만, 카테고리 내부 기준으로 보면 제시할 수 있는 후보가 존재한다.

발표 문장:

```text
전체 순위만 보면 백반·죽·국수 매장이 대부분이지만, 카테고리 내부 순위를 함께 보면 치킨과 피자에서도 성장 후보를 제시할 수 있습니다.
```

## 5. 프로젝트 차별점으로 연결

이번 보정 분석은 다음 차별점을 만든다.

1. 데이터 편중을 숨기지 않고 분석 구조 안에서 보정했다.
2. 전체 Top 매장뿐 아니라 브랜드/카테고리 내부 Top 매장을 제시했다.
3. 교수님이 “본그룹과 굽네치킨밖에 없는데 가능하냐”고 물을 때 방어할 수 있는 근거가 생겼다.
4. GroMong Score를 단일 줄 세우기 도구가 아니라, 여러 관점의 후보 선별 시스템으로 확장했다.

## 6. 발표용 핵심 문장

```text
제공 데이터가 특정 브랜드에 치우쳐 있다는 한계를 인정하고, 전체 점수와 별도로 브랜드 내부, 카테고리 내부 상대 순위를 반영했습니다. 그래서 전체 Top 후보뿐 아니라 같은 업종 안에서 상대적으로 성장 가능성이 높은 매장도 함께 제시할 수 있습니다.
```

## 7. 한계

- 보정 점수는 실제 투자 성과로 검증된 최종 점수가 아니다.
- 브랜드가 2개뿐이므로 브랜드 보정의 일반화에는 한계가 있다.
- 카테고리 표본 수가 다르므로 피자처럼 표본이 작은 카테고리는 해석을 조심해야 한다.
- 따라서 최종 발표에서는 전체 점수, 보정 점수, 외부 상권, 리뷰 NLP를 함께 보는 방식으로 설명해야 한다.
