# Quality Boost Visualization Guide

## `quality_boost_roadmap.svg`

파일:

- `analysis_outputs/quality_boost/charts/quality_boost_roadmap.svg`

## 목적

중간발표에서 1등급 퀄리티로 보이기 위해 남은 보강 과제를 한 장의 로드맵으로 보여준다.

교수님이 중요하게 보는 세 가지 기준인 **차별점, 특이한 외부데이터, 유의미한 분석**을 각각 어떤 추가 작업으로 강화할지 시각적으로 정리한다.

## 구성

로드맵은 5개 보강 과제로 구성된다.

1. 리뷰 NLP
2. 가중치 민감도
3. 처치 전후 효과
4. 브랜드/카테고리 보정 점수
5. 외부데이터 확장

## 색상 의미

여러 색상을 사용해 각 보강 과제의 역할을 구분했다.

| 색상 | 과제 | 의미 |
| --- | --- | --- |
| 보라 | 리뷰 NLP | AI 분석 느낌 강화 |
| 파랑 | 가중치 민감도 | 스코어 공식 방어력 강화 |
| 초록 | 처치 전후 효과 | 분석 깊이 강화 |
| 주황 | 보정 점수 | 브랜드/카테고리 편향 방어 |
| 빨강 | 외부데이터 확장 | 특이하고 차별적인 외부데이터 강화 |

## 해석

현재 프로젝트는 이미 매장-월 패널, 외부 상권 데이터 결합, Growth Alpha 모델, GroMong Score, 데모를 갖추고 있다.

하지만 1등급 중간발표를 위해서는 다음을 보강해야 한다.

- 리뷰 원문을 활용해 AI 분석 느낌을 강화한다.
- 스코어 가중치를 여러 시나리오로 비교해 설계 근거를 강화한다.
- 댓글몽 도입 전후 변화 분석으로 처치효과 관점을 보완한다.
- 브랜드/카테고리 편향을 보정 점수로 방어한다.
- 최종발표를 위해 전국 외부데이터 확장 가능성을 제시한다.

## 발표용 문장

```text
현재 프로젝트는 스코어링과 데모까지 구현되어 있지만, 중간발표에서 차별점을 더 명확히 보이기 위해 5개 보강 과제를 설정했습니다. 특히 리뷰 원문 NLP와 가중치 민감도 분석을 우선 추가해 AI 분석성과 스코어 설계 근거를 강화할 계획입니다.
```

```text
이 보강 로드맵은 단순히 모델 성능을 높이는 것이 아니라, 교수님이 중요하게 보는 차별점, 외부데이터, 유의미한 분석 결과를 더 명확하게 보여주기 위한 전략입니다.
```

## 주의점

- 이 로드맵은 남은 작업 계획을 보여주는 시각화다.
- 이미 완료된 분석 결과와 앞으로 보강할 분석을 구분해서 발표해야 한다.
- 중간발표 전 최소 필수 보강은 리뷰 NLP와 가중치 민감도 분석이다.
