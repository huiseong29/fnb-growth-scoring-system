# Demo Guide

이 문서는 매장 ID 입력형 GroMong Score 데모 사용법을 설명한다.

## 1. 데모 목적

PDF 과제 요구사항 중 필수 항목은 **매장 ID 입력 → 스코어 출력 데모**이다.

본 데모는 `platform_shop_id`를 입력하면 다음 정보를 한 화면에 보여준다.

- 매장 기본 정보
- GroMong Score
- A/B/C/D 등급
- 성장 확률
- 점수 구성요소
- 주요 판단 근거 3개
- 서울 매장인 경우 외부 상권 지표

## 2. 실행 방법

프로젝트 루트에서 다음 명령을 실행한다.

```powershell
& 'C:\Users\tobes\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' app.py
```

기본 주소:

```text
http://127.0.0.1:8765
```

다른 포트를 사용하려면 다음처럼 실행한다.

```powershell
& 'C:\Users\tobes\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' app.py 8770
```

## 3. 입력값

입력값은 `platform_shop_id`이다.

예시:

```text
ba_13248384
```

왼쪽 추천 샘플 목록에서 상위 점수 매장을 클릭해도 된다.

## 4. 화면 구성

### 4.1 점수 게이지

GroMong Score를 0~100점으로 보여준다.

해석:

- 점수가 높을수록 성장 유망 매장으로 우선 검토할 수 있다.
- 단, 점수는 투자 확정이 아니라 우선 검토 후보군을 좁히기 위한 기준이다.

### 4.2 등급 배지

점수를 A/B/C/D로 변환하여 보여준다.

등급 기준:

| 등급 | 기준 | 의미 |
| --- | --- | --- |
| A | 80점 이상 | 투자/운영 지원 우선 대상 |
| B | 65~79점 | 성장 가능성 높음 |
| C | 50~64점 | 관찰 필요 |
| D | 50점 미만 | 성장 신호 약함 |

### 4.3 점수 구성요소 bar chart

최종 점수를 구성하는 요소를 막대그래프로 보여준다.

구성요소:

- 성장 확률 점수
- Growth Alpha 점수
- 리뷰 성장 지수
- 운영역량 지수
- 안정성 지수
- 서울 매장일 경우 상권 적합도

### 4.4 주요 근거

매장별 점수 산출 근거를 최대 3개 문장으로 보여준다.

예시:

```text
브랜드·카테고리 평균 대비 초과 성장 신호가 강함
최근 리뷰 성장 흐름이 우수함
답글률과 응답속도 기준 운영 대응력이 우수함
```

### 4.5 서울 외부 상권 지표

서울 매장일 경우 다음 항목이 추가로 표시된다.

- 상권 평균 객단가
- 매장/상권 객단가 비율

해석:

- 매장을 절대 성과만으로 보지 않고, 같은 자치구·유사업종 상권 대비 위치로 해석한다.
- 이는 본 프로젝트의 차별점인 **상권 대비 성장 유망성 평가**와 연결된다.

## 5. 발표 시연 흐름

권장 시연 순서:

1. 데모 페이지 접속
2. 추천 샘플 중 A등급 매장 클릭
3. 점수 게이지와 등급 배지 설명
4. 점수 구성요소 bar chart 설명
5. 주요 근거 3개 설명
6. 서울 매장 예시를 조회해 외부 상권 지표 설명
7. 존재하지 않는 ID 입력 시 예외 처리 확인

## 6. 주의점

- 현재 데모는 2025-09 기준 점수를 보여준다.
- 외부 상권 지표는 서울 매장 211개에만 적용된다.
- 최종 점수는 실제 투자 확정이 아니라 투자/운영 지원 우선순위 선별용이다.
- 제공 데이터가 본그룹과 굽네치킨 중심이므로 전체 F&B 시장 일반화에는 한계가 있다.
