# Demo Visualization Guide

이 문서는 GroMong Score 데모 화면에 포함된 시각적 요소의 목적과 해석을 정리한다.

## 1. 점수 게이지

위치:

- 데모 메인 결과 화면 왼쪽

목적:

- GroMong Score를 0~100점 범위에서 직관적으로 보여준다.
- 발표자가 매장별 성장 유망성을 즉시 설명할 수 있게 한다.

해석:

- 점수가 높을수록 성장 유망성이 높게 평가된 매장이다.
- 점수는 모델 성장 확률, Growth Alpha, 리뷰 성장, 운영역량, 안정성을 결합한 결과다.

발표용 문장:

```text
이 게이지는 매장의 최종 GroMong Score를 보여줍니다. 단순 매출 규모가 아니라 성장 확률, Growth Alpha, 리뷰 성장, 운영역량, 안정성을 결합한 0~100점 점수입니다.
```

주의점:

- 점수는 투자 확정 판단이 아니라 우선 검토 대상 선별 기준이다.

## 2. 등급 배지

위치:

- 점수 게이지 아래

목적:

- 0~100점 점수를 A/B/C/D 등급으로 변환해 빠르게 해석할 수 있게 한다.

등급 기준:

- A: 80점 이상
- B: 65~79점
- C: 50~64점
- D: 50점 미만

발표용 문장:

```text
점수는 A/B/C/D 등급으로 변환됩니다. A등급은 투자나 운영 지원을 우선 검토할 후보군입니다.
```

주의점:

- 등급 기준은 현재 프로젝트 기준이며, 실제 기업 정책에 따라 조정 가능하다.

## 3. 점수 구성요소 bar chart

위치:

- 데모 결과 화면 오른쪽 중간

목적:

- 최종 점수가 어떤 요소로 구성되었는지 설명한다.
- 블랙박스 점수가 아니라 설명 가능한 스코어임을 보여준다.

구성요소:

- 성장 확률 점수
- Growth Alpha 점수
- 리뷰 성장 지수
- 운영역량 지수
- 안정성 지수
- 서울 매장의 경우 상권 적합도

해석:

- 성장 확률 점수가 높으면 모델이 해당 매장을 성장 가능성이 높다고 본 것이다.
- Growth Alpha 점수가 높으면 같은 브랜드·카테고리 대비 초과 성장 신호가 강하다는 뜻이다.
- 운영역량 점수가 높으면 답글률과 응답속도 측면에서 고객 대응이 좋다는 뜻이다.
- 서울 매장의 상권 적합도는 외부 상권 평균 객단가 대비 위치를 반영한다.

발표용 문장:

```text
최종 점수는 하나의 모델 확률만으로 계산하지 않았습니다. Growth Alpha, 리뷰 성장, 운영역량, 안정성을 함께 반영해 설명 가능한 스코어로 만들었습니다.
```

주의점:

- 구성요소는 모두 같은 중요도를 갖지 않는다.
- 최종 점수에는 사전에 정의한 가중치가 적용된다.

## 4. 주요 근거 카드

위치:

- 점수 구성요소 아래

목적:

- 매장별 점수 산출 이유를 사람이 읽을 수 있는 문장으로 제공한다.
- 발표 시 “왜 이 매장이 높은 점수를 받았는가”를 설명하기 위해 사용한다.

해석:

- 근거 문장은 Growth Alpha, 리뷰 성장, 운영역량, 외부 상권 지표를 기준으로 생성된다.
- 매장별로 최대 3개 근거가 표시된다.

발표용 문장:

```text
각 매장은 점수뿐 아니라 주요 근거 3개를 함께 제공합니다. 따라서 단순 예측값이 아니라 실제 의사결정에 활용 가능한 설명을 제공합니다.
```

주의점:

- 현재 근거 문장은 규칙 기반으로 생성된다.
- 향후 SHAP 기반 개별 설명으로 고도화할 수 있다.

## 5. 서울 외부 상권 지표

위치:

- 결과 화면 하단

목적:

- 서울 매장에 대해 외부 상권 데이터가 어떻게 반영되는지 보여준다.
- 본 프로젝트의 차별점인 상권 대비 평가를 데모 화면에서 직접 확인하게 한다.

표시 항목:

- 상권 평균 객단가
- 매장/상권 객단가 비율

해석:

- 매장/상권 객단가 비율이 높으면 같은 자치구·유사업종 평균 대비 가격 포지션이 높다.
- 이 값은 서울 매장에 한해 최종 점수의 10% 보정 항목으로 반영된다.

발표용 문장:

```text
서울 매장은 외부 상권 데이터를 결합해 같은 자치구·유사업종 평균 객단가와 비교했습니다. 이 부분이 단순 매장 성과가 아니라 상권 대비 성장성을 평가한다는 본 프로젝트의 차별점입니다.
```

주의점:

- 외부 상권 지표는 현재 서울 매장 211개에만 적용된다.
- 현재 결합 단위는 자치구이며, 향후 좌표 또는 행정동 단위로 고도화할 수 있다.

## 6. 추천 샘플 목록

위치:

- 데모 화면 왼쪽

목적:

- 발표 시 빠르게 시연할 수 있는 상위 점수 매장을 제공한다.
- 사용자가 직접 ID를 외우지 않아도 샘플을 클릭해 결과를 볼 수 있다.

해석:

- 추천 샘플은 GroMong Score 상위 매장이다.
- 상위 매장은 투자 확정이 아니라 우선 검토 후보군이다.

발표용 문장:

```text
왼쪽 추천 샘플은 GroMong Score 상위 매장입니다. 클릭하면 해당 매장의 점수, 등급, 구성요소, 주요 근거를 바로 확인할 수 있습니다.
```

주의점:

- 상위 샘플이 특정 브랜드에 몰릴 수 있으므로 브랜드 편향 가능성을 함께 언급해야 한다.
