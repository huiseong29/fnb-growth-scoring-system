# Midterm Quality Boost Plan

이 문서는 중간발표에서 1등을 노리기 위해 현재 프로젝트의 부족한 부분을 어떻게 보강할지 정리한다.

현재 프로젝트는 이미 다음을 갖추고 있다.

- 데이터 구조 파악
- 외부 서울 상권 데이터 결합
- 매장-월 패널 구축
- EDA
- Baseline vs Growth Alpha 모델 비교
- 서울 외부 상권 데이터 효과 검증
- GroMong Score 산출
- 매장별 설명 근거
- 매장 ID 입력형 데모
- 시각화 및 시각화 해석 문서

하지만 교수님이 원하는 것은 **명확한 차별점, 특이한 외부 데이터, 유의미한 분석 결과**이므로, 중간발표 전까지 아래 보강 과제를 수행하면 완성도가 크게 올라간다.

## 1. 보강 방향 요약

핵심 발표 메시지는 유지한다.

```text
저희는 단순히 현재 잘되는 매장을 찾는 것이 아니라,
상권과 브랜드 효과를 보정한 뒤에도 성장 가능성이 높은 매장을 찾습니다.
```

보강은 이 메시지를 더 강하게 만드는 방향으로 진행한다.

## 2. 우선순위별 보강 과제

## Priority 1. 리뷰 텍스트 감성/키워드 분석 추가

상태: **진행 중**

### 왜 필요한가

현재 리뷰 데이터는 리뷰 수, 평점, 답글률, 응답속도 중심으로 사용하고 있다. 하지만 PDF에서는 리뷰 원문과 NLP 분석을 강조한다.

AI빅데이터학과 프로젝트로 보이려면 리뷰 텍스트 원문을 활용한 분석이 들어가는 것이 좋다.

### 목표

리뷰 원문에서 긍정/부정/운영 관련 키워드를 추출하고, 성장 매장과 비성장 매장의 리뷰 언어 차이를 비교한다.

### 수행 작업

- 리뷰 텍스트 정제
- 긍정 키워드 사전 생성
- 부정 키워드 사전 생성
- 배달/포장/맛/양/가격/응대 관련 키워드 분류
- 매장-월 단위 감성 점수 생성
- 성장 라벨 1 vs 0 감성 점수 비교
- 별점과 텍스트 감성 불일치 사례 탐색
- 감성 지수를 GroMong Score 보조 설명 변수로 연결

### 예상 산출물

- `analysis_outputs/nlp/review_text_features.csv`
- `analysis_outputs/nlp/review_sentiment_summary.csv`
- `analysis_outputs/nlp/review_keyword_summary.csv`
- `analysis_outputs/nlp/review_sentiment_report.md`

### 필수 시각화

- 성장/비성장 리뷰 감성 점수 비교
- 긍정 키워드 Top 20
- 부정 키워드 Top 20
- 별점-감성 불일치 사례 분포
- 카테고리별 리뷰 감성 비교

### 발표용 문장

```text
리뷰 별점만으로는 고객 반응을 충분히 설명하기 어렵기 때문에, 리뷰 원문에서 맛, 양, 가격, 배달, 응대 관련 감성 신호를 추출했습니다.
```

```text
이 분석을 통해 정량 지표뿐 아니라 고객 언어에서 드러나는 성장 신호까지 스코어링에 연결했습니다.
```

## Priority 2. 스코어 가중치 민감도 분석

상태: **진행 예정**

### 왜 필요한가

현재 GroMong Score의 가중치는 합리적 파일럿 설계값이다. 하지만 교수님이 “왜 이 가중치인가?”라고 물으면 더 강한 방어 논리가 필요하다.

### 목표

여러 가중치 시나리오를 비교해 현재 가중치가 어떤 성격을 갖는지 보여준다.

### 비교할 시나리오

| 시나리오 | 설명 |
| --- | --- |
| Current | 현재 기본 가중치 |
| Model-heavy | 성장 확률 점수 비중 강화 |
| Alpha-heavy | Growth Alpha 비중 강화 |
| Operation-heavy | 운영역량 비중 강화 |
| Balanced | 모든 지수 균형 배분 |

### 예상 산출물

- `analysis_outputs/weight_sensitivity/weight_scenarios.csv`
- `analysis_outputs/weight_sensitivity/weight_sensitivity_report.md`

### 필수 시각화

- 시나리오별 등급 분포
- 시나리오별 Top 100 중복률
- 시나리오별 브랜드/카테고리 편향 비교

### 발표용 문장

```text
스코어 가중치를 하나로 고정해서 끝내지 않고, 여러 가중치 시나리오를 비교해 최종 점수의 안정성과 해석 가능성을 점검했습니다.
```

## Priority 3. 처치 전후 효과 분석

상태: **진행 예정**

### 왜 필요한가

현재 `is_post_treatment`는 모델 feature로 사용되었지만, 댓글몽 도입 전후 효과를 별도로 깊게 분석하지는 않았다.

PDF에는 실험군/통제군과 처치효과 검증 구조가 포함되어 있으므로, 간단한 전후 비교라도 추가하면 분석 깊이가 올라간다.

### 목표

처치 전후 주문, 리뷰, 답글률 변화가 있는지 확인한다.

### 수행 작업

- 처치 전 3개월 vs 처치 후 3개월 비교
- 주문수 변화
- 리뷰수 변화
- 답글률 변화
- 실험군/통제군 비교
- 이벤트 월 기준 평균 추이 시각화

### 예상 산출물

- `analysis_outputs/treatment/treatment_effect_summary.csv`
- `analysis_outputs/treatment/treatment_effect_report.md`

### 필수 시각화

- 처치 전후 주문수 변화
- 처치 전후 리뷰수 변화
- 처치 전후 답글률 변화
- 이벤트 타임라인 그래프

### 발표용 문장

```text
댓글몽 도입 시점을 기준으로 전후 성과 변화를 비교해, 단순 상관이 아니라 서비스 활용 전후의 변화도 함께 확인했습니다.
```

## Priority 4. 브랜드/카테고리 보정 점수 추가

상태: **진행 예정**

### 왜 필요한가

현재 상위 점수 매장이 본그룹/백반·죽·국수에 많이 몰리는 경향이 있다. 이 문제를 숨기지 않고 보정 지표를 추가하면 방어력이 좋아진다.

### 목표

전체 순위와 별도로 브랜드/카테고리 내부 순위를 만든다.

### 수행 작업

- 브랜드별 percentile score 생성
- 카테고리별 percentile score 생성
- 전체 GroMong Score와 보정 score 비교
- 카테고리별 Top 매장 추출

### 예상 산출물

- `analysis_outputs/calibrated_score/category_ranked_scores.csv`
- `analysis_outputs/calibrated_score/calibrated_score_report.md`

### 필수 시각화

- 전체 점수 vs 카테고리 내부 순위 비교
- 카테고리별 Top 10 매장
- 브랜드별 A등급 비율 비교

### 발표용 문장

```text
데이터가 특정 브랜드에 치우쳐 있다는 한계를 고려해, 전체 점수뿐 아니라 같은 브랜드·같은 카테고리 내부에서의 상대 순위도 함께 확인했습니다.
```

## Priority 5. 외부 데이터 확장 후보 조사

상태: **선택 진행**

### 왜 필요한가

현재 외부 데이터는 서울 211개 매장에 안정적으로 결합되어 있다. 중간발표에서는 충분히 쓸 수 있지만, 최종발표에서는 전국 확장 가능성을 보여주는 것이 좋다.

### 후보 데이터

- 소상공인시장진흥공단 상가업소정보
- 행정안전부 인허가/폐업 데이터
- 관광/방문자 데이터
- 날씨 데이터
- 지역 인구/소득/생활인구 데이터

### 예상 산출물

- `external_data_candidates.md`
- 외부 데이터 확장 로드맵

### 발표용 문장

```text
중간 단계에서는 서울시 상권분석 데이터를 검증용 외부 데이터로 사용했고, 최종 단계에서는 전국 상가업소정보와 인허가/폐업 데이터를 결합해 전국 확장성을 높일 계획입니다.
```

보강 후 발표 메시지는 다음처럼 정리한다.

```text

여기에 서울시 상권분석 외부 데이터를 추가해 상권 대비 성장성을 평가했고,
리뷰 원문 분석을 통해 고객 언어에서 드러나는 성장 신호까지 반영했습니다.
```

