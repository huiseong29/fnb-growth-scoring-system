# AI 기반 F&B 성장 유망 매장 스코어링 시스템 기획서

## 1. 프로젝트명

**AI 기반 F&B 성장 유망 매장 스코어링 시스템**

부제:

**외부 상권 데이터와 Growth Alpha를 활용한 투자 유망 매장 선별**

## 2. 문제 정의

F&B 시장에서 투자하거나 운영 지원을 집중할 매장을 고르는 일은 쉽지 않다. 단순히 현재 주문이 많거나 리뷰가 많은 매장이 반드시 앞으로도 성장할 매장이라고 볼 수 없기 때문이다.

예를 들어, 대형 상권에 위치한 매장은 상권 자체의 유동성과 수요 덕분에 높은 성과를 낼 수 있다. 반대로 상대적으로 불리한 상권에서도 꾸준히 주문과 리뷰가 성장하는 매장은 매장 자체의 운영 역량이나 성장 잠재력이 높을 수 있다.

따라서 본 프로젝트는 다음 질문에 답하는 것을 목표로 한다.

```text
어떤 F&B 매장이 앞으로 성장할 가능성이 높은가?
그리고 그 성장은 상권 덕분인가, 매장 자체의 경쟁력 때문인가?
```

## 3. 프로젝트 목표

본 프로젝트의 목표는 주문, 리뷰, 메뉴, 매장 정보, 처치 시점, 외부 상권 데이터를 결합하여 **F&B 매장의 성장 가능성을 0~100점으로 점수화하는 AI 기반 스코어링 시스템**을 구축하는 것이다.

최종적으로 매장 ID를 입력하면 다음 결과를 제공하는 데모를 구현한다.

- 성장 확률
- Growth Alpha
- 그로몽 스코어
- A/B/C/D 투자 등급
- 주요 판단 근거

## 4. 핵심 차별점

본 프로젝트의 핵심 차별점은 **Growth Alpha**이다.

일반적인 접근은 다음과 같다.

```text
주문이 많다 + 리뷰가 많다 + 평점이 높다 = 좋은 매장
```

하지만 본 프로젝트는 다르게 접근한다.

```text
상권이 좋아서 잘되는 매장인가?
브랜드가 강해서 잘되는 매장인가?
아니면 같은 조건에서 매장 자체가 초과 성장하는 것인가?
```

이를 위해 브랜드, 카테고리, 지역 상권 효과를 보정한 초과 성장 지표를 만든다.

```text
Growth Alpha =
매장 성장률
- 브랜드 평균 성장률
- 카테고리 평균 성장률
- 외부 상권 성장 또는 수준 효과
```

즉, 본 프로젝트는 단순 인기 매장 추천이 아니라 **상권·브랜드 효과를 보정한 투자 유망 매장 발굴 모델**이다.

## 5. PDF 과제 주제와의 연결

PDF에서 제시한 핵심 주제는 **식당판 신용점수**이다.

KCB, NICE가 금융 데이터를 바탕으로 개인의 신용도를 평가하듯이, 본 프로젝트는 F&B 매장의 운영 데이터를 바탕으로 성장 가능성을 평가한다.

PDF 요구사항과 본 프로젝트의 연결은 다음과 같다.

| PDF 요구사항 | 본 프로젝트 대응 |
| --- | --- |
| 성장 유망 매장 예측 | 성장 라벨 기반 AI 모델 구축 |
| 그로몽 스코어 0~100점 | 매장별 GroMong Score 산출 |
| 리뷰·운영·주문 데이터 활용 | 주문, 리뷰, 답글, 메뉴, 처치 시점 변수 사용 |
| 외부 데이터 활용 | 서울시 상권분석서비스 추정매출 데이터 결합 |
| 알고리즘 선택 근거 | Baseline vs Growth Alpha 모델 비교 |
| 검증 결과 수치 제시 | AUC, Precision, Recall, F1, Top N 적중률 |
| 구현 화면 시연 | 매장 ID 입력형 데모 구현 |

## 7. 데이터 한계와 대응 전략

현재 제공 데이터는 전체 F&B 시장의 완전한 대표 표본이 아니다. 브랜드는 주로 본그룹과 굽네치킨으로 구성되어 있다.

이 한계를 숨기지 않고 다음과 같이 해석한다.

```text
본 프로젝트는 전체 F&B 시장을 완전히 대표하는 모델을 주장하지 않는다.
제공된 실제 F&B 운영 데이터를 파일럿 데이터셋으로 사용하여,
성장 유망 매장 스코어링 방법론의 유효성을 검증한다.
```

브랜드 편향에 대한 대응:

- 브랜드를 예측 근거가 아니라 통제 변수로 사용
- 브랜드별 평균 성장률 계산
- 매장 성장률에서 브랜드 평균 성장률을 차감
- 카테고리별 평균 성장률도 함께 차감
- Growth Alpha를 통해 매장 자체의 초과 성장력을 추정

## 8.1.1 EDA 결과 요약

매장-월 패널을 대상으로 1차 EDA를 수행했다.

주요 결과:

- 성장 라벨 1 그룹 평균 월 주문수: 169.17
- 성장 라벨 0 그룹 평균 월 주문수: 68.18
- 성장 라벨 1 그룹 평균 월 리뷰수: 14.90
- 성장 라벨 0 그룹 평균 월 리뷰수: 8.81
- 성장 라벨 1 그룹 평균 답글률: 0.5505
- 성장 라벨 0 그룹 평균 답글률: 0.4702
- 성장 라벨 1 그룹 평균 `internal_growth_alpha`: 2.9508
- 성장 라벨 0 그룹 평균 `internal_growth_alpha`: -1.2651

해석:

```text
성장 라벨 1 그룹은 성장 라벨 0 그룹보다 주문수, 리뷰수, 답글률이 높다.
결과 설명용 Growth Alpha 역시 성장 그룹과 비성장 그룹을 뚜렷하게 구분한다.
```

단, `internal_growth_alpha`는 미래 성장률에서 파생된 변수이므로 예측 모델 입력에는 사용할 수 없다. 예측 모델에는 과거 데이터만으로 계산한 `historical_internal_growth_alpha`를 사용한다.

## 8.2 성장 라벨 정의

성장 유망 매장 예측을 위해 정답 라벨을 직접 생성한다.

기본 아이디어:

```text
최근 3개월 평균 성과와 이후 3개월 평균 성과를 비교하여 성장 여부를 판단한다.
```

복합 성장 점수:

```text
composite_growth_score =
0.5 * 주문 성장률
+ 0.3 * 매출 성장률
+ 0.2 * 리뷰 성장률
```

성장 라벨:

```text
복합 성장 점수 상위 30% = 성장 유망 매장 1
나머지 = 비성장 또는 일반 매장 0
```


## 9.2.1 Baseline vs Growth Alpha 모델 결과

시간 기준 분할로 Baseline 모델과 Growth Alpha 모델을 비교했다.

검증 방식:

- 학습 기간: 2025-01 ~ 2025-07
- 검증 기간: 2025-08 ~ 2025-09
- 목표 변수: `growth_label_top30`

성능 결과:

| 모델 | AUC | F1 | Precision | Recall |
| --- | ---: | ---: | ---: | ---: |
| Baseline | 0.6060 | 0.5173 | 0.3698 | 0.8603 |
| Growth Alpha | 0.6078 | 0.5169 | 0.3694 | 0.8603 |

Top N 추천 성능:

| 모델 | Top 50 Precision | Top 100 Precision | Top 200 Precision |
| --- | ---: | ---: | ---: |
| Baseline | 0.340 | 0.400 | 0.395 |
| Growth Alpha | 0.340 | 0.420 | 0.405 |

해석:

```text
과거 기반 Growth Alpha를 추가했을 때 AUC와 Top N precision이 소폭 개선되었다.
개선 폭은 크지 않지만, 브랜드·카테고리 보정 성장 신호가 성장 유망 매장 선별에 일부 기여한다는 근거로 활용할 수 있다.
```

다만 Growth Alpha는 현재 단계에서 강력한 단독 예측 변수라기보다는, 본 프로젝트의 차별점인 **상권·브랜드·카테고리 보정 기반 스코어 설명 요소**로 활용하는 것이 더 타당하다.

```text
외부 상권 데이터가 단순히 붙인 데이터가 아니라,
성장 유망 매장 선별 성능을 실제로 개선하는지 검증한다.
```

## 9.3.1 외부 상권 데이터 효과 검증 결과

서울 매장 211개 subset에서 외부 상권 변수 추가 전후 성능을 비교했다.

성능 결과:

| 모델 | AUC | F1 | Precision | Recall |
| --- | ---: | ---: | ---: | ---: |
| Seoul Internal | 0.5826 | 0.4807 | 0.3323 | 0.8689 |
| Seoul External | 0.5995 | 0.4773 | 0.3302 | 0.8607 |

Top N 추천 성능:

| 모델 | Top 50 Precision | Top 100 Precision | Top 200 Precision |
| --- | ---: | ---: | ---: |
| Seoul Internal | 0.360 | 0.340 | 0.325 |
| Seoul External | 0.360 | 0.370 | 0.330 |

해석:

```text
외부 상권 변수를 추가했을 때 AUC가 0.5826에서 0.5995로 개선되었다.
Top 100 precision도 0.340에서 0.370으로 개선되었다.
```

중요 변수에서도 `store_vs_market_ticket_ratio`, `market_q4_avg_ticket`이 상위에 포함되었다. 이는 매장 자체 성과뿐 아니라 상권 평균 객단가 대비 위치가 성장 유망 매장 선별에 의미 있는 신호가 될 수 있음을 보여준다.

따라서 외부 상권 데이터는 단순 부가 데이터가 아니라, 본 프로젝트의 차별점인 **상권 대비 성장 유망성 평가**를 뒷받침하는 실증 근거로 사용할 수 있다.

검증 목적:

```text
외부 상권 데이터를 결합하면 성장 예측 성능이 개선되는가?
```
